# Центр Плова — сайт кафе

Одностраничный адаптивный сайт кафе «Центр Плова» (Ульяновск, пр-т Зырина, 13).
«Вкус Востока, тепло для души».

Всё в одном файле `index.html` (разметка, CSS и JS внутри), фото в папке `img/`.
Внешние зависимости: только шрифты Google Fonts (Unbounded, Manrope) и виджет Яндекс.Карт.

Дизайн: тёмная тема в цветах вывески (графит + золото), карусель блюд в первом экране
(блюдо сменяется с поворотом), стеклянные карточки блюд, меню с карточкой раздела.
Фото увеличены нейросетью EDSR (×4) и очищены от артефактов сжатия.

## Как править

Откройте `index.html` и найдите по Ctrl+F слово **МЕНЯТЬ**: так помечены все места,
где меняются тексты, цены, фото, телефон, адрес, часы и соцсети.

- **Цены и меню** — раздел «4. МЕНЮ». Одна строка — одно блюдо.
- **Фото** — положите свой файл в `img/` с тем же именем (лучше `.webp`, 1200–1600 px по длинной стороне)
  или поменяйте путь в `src="..."`. Плейсхолдеры `<div class="ph">` замените на `<img ...>`.
- **Телефон** — в `href="tel:+79278372181"` и в видимом тексте.
- **Соцсети** — в подвале: вставьте ссылки и уберите атрибут `hidden` у блока `.socials`.

## Безопасность

- В `index.html` задана Content-Security-Policy: скрипты выполняются только встроенный
  (по SHA-256 хэшу), загрузка — только с Google Fonts и Яндекс.Карт, формы и плагины запрещены.
- Все внешние ссылки открываются с `rel="noopener noreferrer"`.
- В репозитории нет ключей и паролей; `.gitignore` не пустит `.env` и ключи.

**Если меняете код скрипта** в конце `index.html`, пересчитайте хэш, иначе скрипт не запустится
(браузер подскажет правильный хэш в консоли), например:

```sh
python3 -c "import re,hashlib,base64;s=open('index.html',encoding='utf-8').read();b=s.split('<script>')[-1].split('</script>')[0];print(base64.b64encode(hashlib.sha256(b.encode()).digest()).decode())"
```

и вставьте результат в `script-src 'sha256-…'`.
